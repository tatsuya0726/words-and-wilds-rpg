# ごちゃまぜモンスター / Words & Wilds

ドット絵の魔獣を育て、英語を呪文に変えて旅をするブラウザーRPGの試作です。

**プレイ:** https://tatsuya0726.github.io/words-and-wilds-rpg/

## 遊び方

1. 「タップして開始」→タイトル画面の「スタート」を押します。初回は最初に小1入門〜中3目安の学習帯を選択します。
2. ワールドからエリアに入り、明るいマスを押して探索します。探索で周囲の道が開き、分岐を自由に選べます。
3. 戦闘は呪文を選んで英語問題に回答します。正解なら100%、不正解でも50%の効果。制限時間はありません。
4. 勝利で経験値・星砂・仲間を獲得。配合工房では決まった2種から既存の別種を迎えます。
5. 町のキキ・ネネは英語で話します。「日本語を重ねる」で英語を残したまま訳を表示できます。

PC・縦画面・横画面に対応。操作はクリック/タップです。

## 試作の範囲

- 地上3エリア、地下1区画、空中1区画、合計35マス。
- 8種の魔獣、固定配合3レシピ、攻撃呪文3種と回復呪文1種。
- 英語問題370問、学習帯9段階、各帯に基礎・標準・挑戦の3段階。
- キキ・ネネの会話と表情差分。
- このサイトの同じブラウザーに自動保存。端末・ブラウザーが変わると自動では引き継がれません。

地下・空中の背景は既存画像を仮使用しています。世界全域、配合の拡充、技継承、BGMは未実装です。配合は試作用に「親を残し、星砂3で未加入の子を迎える」ルールです。
学習帯・難易度はゲーム内の目安であり、学校の正式な学年配当を保証するものではありません。
自動保存・再開は確認済みですが、設定の保存ファイル書き出し/読み込みは実機検証が完了していません。
